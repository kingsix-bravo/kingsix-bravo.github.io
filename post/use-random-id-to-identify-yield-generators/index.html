use random id to identify yield-generators

2019-08-10 1 min read

code is:

import random

def nexter(max):
    n=1
    id=random.random()
    while n<max:
        print id
        yield n
        n=n+1
        

for a in nexter(4):
    for b in nexter(4):
        print a,b
